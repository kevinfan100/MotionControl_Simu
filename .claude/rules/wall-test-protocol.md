# 未知牆測試協定（2026-09-21 使用者裁示）

> 來源：δ 法則線（C65–C69）。seed = plant 與家族中點 prior 的臂都在「對答案」——
> 實驗裡我們永遠不知道眼前的牆是哪一種，唯一有已發表精確法則的牆是平面。
> 目標不變：**對任一牆面都要把 ā 估準**（CLAUDE.md 研究主線）。

1. **估測器一律從平面出發。** 任何臂的 init = 平面法則的值：δ̂[0] = 0、[1/1] 用平面常數
   (−0.984, 0.161)、Form C 用 8/9；w̄_s = 可見表面；prior 寬度由推導給（雙邊、不讀測試牆）。
   seed = plant、家族中點、真值種子只准當 sanity／參考臂，不得當主判定，不得進結論鏈。
2. **牆是 plant 的事，估測器不得被告知。** 測試牆至少三種：平面（零代價檢查 = 負控制）、
   細胞（平面下移 1.05 R，位置型，`cell_cperp_delta.m`）、球面（形狀型，O30）；
   加新牆時估測器 code 一行不改，只換 `opts.plant_cperp`。
3. **判準 = 對每一種牆的 ā 準度**：運動段優先、e_ā = ā_true − â 絕對值、hold 最後
   （figure-style.md）；平面的代價必須與其他牆並列報告，不能只報改善的那面牆。
4. **只在某個家族內有效的方法 = 家族限制，不是解。** δ 法則只對「平面平移」的牆有效
   （C62／C69），對球面無效 ⇒ 入帳為限制，不再停留。任何新方法先問：牆不在家族內時它會怎樣。
5. **圖**：同一列 = 同一 init（平面）× 不同牆，共用 y 軸；legend 標「plane init」；
   參考臂（seed = plant）若要放，另開一列並標明是參考。
