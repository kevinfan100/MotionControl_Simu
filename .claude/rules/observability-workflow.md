# 可觀性檢查工作流

新增（或重新審查）一個 filter state 時走這五關。**前三關在紙上，寫進 `.tex`；後兩關跑
`verify_state_observability.m`。** 任一關判死就停，不用往下走。

可觀性只問一件事：**只看得到輸出 y，能不能唯一反推出狀態 x？** 若存在兩組不同的狀態值
產生完全相同的輸出序列，你永遠分不出是哪一組 —— 濾波器不會報錯，它會給你一個看起來合理
但由 prior 而非資料決定的估值。整套檢查就是去找這種「輸出相同」的成對狀態。

時變系統（F_e、H 每步在變）不能用 LTI 的 `rank([C; CA; CA²…])`。正式判準是
**uniform complete observability**：存在視窗長度 N 與 α > 0，使每一個長度 N 的視窗都滿足
`G(k, k+N) = Σ Φ' H' R⁻¹ H Φ ≥ α·I`。這是 EKF 收斂定理的前提。所以「可觀」不是布林值，
是「秩 + α 有多大」兩件事：第 4 關量秩，第 5 關量 α。

---

## 範圍：對誰做？

| 關 | 範圍 |
|---|---|
| 1、2、3（紙上） | **per-pair**：新狀態 θ × 每個舊狀態。「什麼條件下會撞」是兩個狀態之間的關係 |
| 4、5（數值） | **整組自由槽一起算**。不可觀常成對發生（θ 與某舊狀態變成只看得到兩者的和），只算 θ 會漏掉受害者 |

鎖住／inert 的槽**不要**列進自由槽：pinned slot 依定義不可觀，會跟真發現混在一起。它的
正確用途是當第 4 關的負控制。

## 五關

### 第 1 關 · 兩條欄位在不在（紙筆，2 分鐘）

```
路 A（狀態路）：∂(某狀態方程)/∂θ  →  F_e 的第 θ 欄   間接、慢，但會累積 ⇒ 通常較強
路 B（量測路）：∂y/∂θ            →  H 的第 θ 欄     直接、快，但通常只有一步的量
```

- 兩條都恆為 0 → **① 死狀態，結案**
- 至少一條非 0 → 過關

⚠ **這一關只能判死不能判活。** 欄位非 0 不代表可觀（第 4 關才算）；欄位為 0 也可能靠
交叉協方差補路 —— formC 的 `H₁` 對 δa 的欄位恆為 0，δa 的資訊卻 97% 從 y₁ 來
（經 `F_e(3,4) = −F_dw` 建的 `P(4,1)`）。**直接讀 Jacobian 欄位會給錯答案。**

### 第 2 關 · 時間簽名跟誰撞（紙筆，5 分鐘）

寫下「θ 有誤差時，輸出上是什麼形狀」，跟現有每個狀態並排比：常數狀態 → 定值偏移；
積分器狀態 → 斜坡；∝ 命令速度的項 → 與速度同相的振盪。

- 形狀跟某舊狀態完全相同 → **② 別名（共線），只能估兩者的組合**
- 形狀不同 → 過關

### 第 3 關 · 什麼條件下會撞（紙筆＋一行數值，10 分鐘）★ 最值錢

把 θ 和「最像它的那個舊狀態」抽成 2 狀態子系統（其餘當已知），算行列式：

```
A₂ = [[F(θ舊,θ舊), F(θ舊,θ)], [0, 1]]        θ 是常數 ⇒ 第二列 [0 1]
C₂ = [H(y,θ舊), H(y,θ)]
det O₂ = det([C₂; C₂·A₂])
```

**把 `det O₂ = 0` 解出來，那個條件就是可觀性喪失的物理條件，必須寫進 `.tex`。**
只給 PASS 不算 —— 要給「什麼場景會壞」。這一關的產出可以拿去檢查任何新場景，第 4、5 關
只告訴你「這次這條軌跡上怎樣」。

### 第 4 關 · 秩測試 ＋ 負控制（`verify_state_observability.m`）

沿**真實軌跡**（不是凍結工作點）疊 `O = [H_k·Φ(k,k₀)]`，取 `rank(O(:, 自由槽))`。

**負控制是強制的，腳本沒給就 error。** 丟一個已知不可觀的方向（pinned inert 槽）進去，
它必須回報不可觀。秩測試有三種靜默失效 —— tolerance 設錯、Φ 連乘溢位、槽位列錯 ——
每一種都回傳一個看起來合理的整數而不是錯誤。**沒有負控制的秩測試不算證據。**

判準：`rank(O) = numel(free)`（少掉的那一維正是負控制）且負控制 CRLB = Inf。

### 第 5 關 · CRLB 對照 prior 寬度（同一支腳本）

`G = Σ Φ' H' R⁻¹ H Φ`（對 x[k₀] 的 Fisher 資訊），`√[G⁻¹]_θθ` = 其他自由狀態皆未知時
θ 的精度下界。

⚠ **用特徵分解算，不要用 pinv。** 不可觀方向的 CRLB 是 +Inf，pinv 把零空間映到 0，
於是不可觀的槽會回報成**全濾波器裡變異數最小**的狀態。2026-08-17 第一版就中，pinned
負控制被報成 4.4e-19。

| CRLB vs √P[0] | 判決 |
|---|---|
| 全視窗 < prior | PASS |
| 部分視窗 < prior | PASS（motion-only）—— 必須報「其他區段是凍結的」 |
| 全視窗 > prior，但有在 2× 內 | TIGHT |
| 全視窗 > prior | **④ 資訊淹沒**：形式可觀但實務不可辨識。處置 = 降級回 prior，或用代數吃掉自由度（MBAM）。**不是**開 Q 逼它動 |

同一支腳本一律連帶產出**通道拆解**（每個量測通道各關一次 = 資訊從哪來）與**區段拆解**
（按場景分段 = 資訊什麼時候到）。「可觀」而不講來源與時機，在這個專案已反覆證明是錯的摘要。

**兩個必須記住的限制**：

- **CRLB 只對 Q = 0 的槽有意義**，而且**即使如此它仍偏樂觀**。G 只累積量測資訊、
  不含過程雜訊：對被估的那個常數（b、p、w̄_s、δa，Q=0）是正確的假設，但它同時把
  **干擾狀態**（δw̄ 鏈、MA 記憶，Q > 0）當成從 x[k₀] 完全可預測，於是高估了能歸給
  該常數的資訊。被 Q > 0 驅動的槽本身印出來的數字更是**不能**當可達誤差讀。
  量到的差距（08-17，formC_b 的 b）：濾波器整段 4.8 s 取得的資料資訊等效 σ = 0.126，
  本腳本的界限說 0.0119 可達 —— σ 差 11×、資訊差 124×，**界限偏樂觀那一側**。
  ⇒ 要回答「不確定度最多能縮多少」，用**濾波器自己的 √P**（此例 0.013795 → 0.013713，
  縮 0.6%），不要用本腳本的比值。本腳本回答的是「結構上有沒有資訊」，不是「能縮多少」。
  未結案：那 124× 是本腳本漏 Q，還是濾波器對 b 次佳，尚未分開（判別法 = 帶 Q 的
  information-filter 遞推對照同視野的 P）。

- **界限隨視野飽和 —— 資訊由「行程」買，不由觀測時間買**（08-17，formC_b 的 b）：

  | 視窗（步） | 125 | 250 | 500 | 1000 | 2000 |
  |---|---|---|---|---|---|
  | CRLB/prior | 4.71 | 1.92 | 1.10 | 0.866 | 0.861 |

  1000 → 2000 只買到 0.5%。因為 b 是 dā/dw̄ 裡的常數，靠**走過 w̄ 的範圍**換取，
  而振盪只是重複造訪已經走過的高度。⇒ **拉長 run 沒用，要改軌跡**（增加「近壁且在
  運動」的時間，因為 ∂ā/∂b = −(1−ā)/b 在遠場趨零）。
- **它是線性化的界限，不是濾波器表現的預測。** G 只由 (F_e, H, R) 建成，看不到 clamp、
  gate、lock 旗標與非線性。第 5 關 PASS **不保證**濾波器真的在用那些資訊 ——
  2026-08-17 b 的 CRLB/prior = 0.86（可用），實際上 b̂ 被抄錯的 clamp 釘死。
  要補這個縫，就把 run 的 √P[end] 拿去跟整段 CRLB 比：濾波器宣稱的不確定度遠大於界限，
  就是有東西在擋。

## 不可觀只有四種原因（＋一種假貨）

| 類型 | 物理意義 | 在哪一關抓到 | 判準 |
|---|---|---|---|
| ① 死狀態 | θ 對世界沒有任何影響 | 1 | F_e、H 的 θ 欄都恆為 0 |
| ② 別名（共線） | θ 和某舊狀態做同一件事 | 2 | 輸出時間形狀相同 |
| ③ 條件退化 | 一般可觀，特定工作點下簽名重合 | **3** | `det O₂ = 0` 的解 |
| ④ 資訊淹沒 | 結構可觀，但訊號小於雜訊或短於 run | 5 | CRLB > prior（全視窗） |
| ⑤（假貨）通道被關掉 | 結構完全可觀，只是那步沒量測 | 4 | gate 觸發比例、旗標接線 |

⑤ **不是理論結論而是實作缺陷**，處置方式完全不同。動任何旗標前先 grep 確認它有接線
（`opts.y2_on` 曾只改檔名與表頭，整輪 T2 因此作廢）。

## 現役家族可觀性總表（2026-08-17 實測）

z 軸、seed 7、canonical 4.8 s、視窗 500 步（0.31 s）× 15 段、y₁+y₂ 全開。
`CRLB/prior` 取**最好的那個視窗**（最寬容的讀法）。

| 臂 | 自由形狀槽 | 第 4 關 rank | ā_w | b | p | w̄_s | δa |
|---|---|---|---|---|---|---|---|
| `formC_dist` (arm dist) | δa | 滿（8/8） | **0.032** PASS | — | — | — | **0.032** PASS |
| `formC_b` (arm best) | b | 滿（8/8） | **0.021** PASS | **0.86** PASS（勉強，飽和值） | — | — | — |
| `formB_ws` t1（production） | b, p | 滿（8/8）σ 1.1e−4 | **0.51** PASS | **4.48 FAIL** | **6.08 FAIL** | 鎖 | — |
| `formB_ws` t2 | b, p, w̄_s | **掉到 8/9** σ 1.8e−6 | **0.65** PASS | **136 FAIL** | **58.9 FAIL** | **6.5 FAIL** | — |

（`formB_ws` t2 的 `Pf_ws_std = 0.111` 是從 formC drivers 的 `Pf_w0_std` **借來**的房規值，
本臂沒有推導預設 —— 只影響 w̄_s 那一欄的比值，b/p 的判決不受它影響。）

**四個可以直接用的結論**：

1. **所有形狀槽在 hold 都失去資訊**，兩端 hold 的 CRLB 全部掉到雙精度解析度以下
   （腳本標 `beyond numerical resolution`，不是真的無限大）。這不是缺陷，是
   `資訊率 ∝ v_d²/a` 的直接後果。
2. **一個形狀參數可以，兩個就不行。** formC 系列（單參數）PASS；formB_ws t1（b, p 兩個）
   兩者都 FAIL，最好的視窗仍差 prior 4.5–6×。這與 08-06 量到的「b 的資料比 prior 弱 5.7×」
   方向一致，也是 production 跑錨定臂的正當理由。
3. **三個就連秩都掉。** t2 的 rank 在部分視窗從 9 掉到 8，σ_min/σ_max = 1.8e−6
   ⇒ **② 別名**（三個形狀參數只約束到某個組合），不只是 ④ 資訊淹沒。獨立重現了
   07-31 的 tier 決策與 08-02 Stage 1b 的「ws 維持 z-only」。
4. **多加一個形狀槽會拖累 ā_w 自己**：ā_w 的絕對 CRLB 從 t1 的 0.001449 變成 t2 的
   0.001834（1.27×）。這就是「不可觀成對發生、受害者不只新來的那個」的量。

## 「什麼條件下估不出來」——逐 state 的實測條件

用 `test_script/scratch/probe_shape_info_rate.m` 直接讀 production 每步建的 Jacobian 欄位。
量測資訊 `I = H₂(θ)²/R₂`；欄位過零 = 該條件下資訊歸零。

| 條件 | 判準 | δa (formC_dist) | b (formC_b) | b, p (formB_ws t1) |
|---|---|---|---|---|
| **A · hold** | 命令速度 = 0 | **不失效**，保留中位資訊的 46% | **完全失效**，I = 0 | **完全失效**，I = 0 |
| **B · 轉折點** | `∇_d w̄_d = 0` | **不失效**（H₂ 欄 0 次過零） | 失效（9 次過零） | 失效（14 次過零） |
| **C · Jacobian 內部零點** | `J_θ(w̄) = 0` 有解且落在工作帶內 | 無（欄位是常數 −d） | **無**（J_b = −ā′/b 不換號） | **有：w̄ = 1 + b̂ ≈ 2.125** |

**條件 A/B 為什麼 δa 免疫**：它的兩條路都是結構常數（`F_e(4,5) = 1`、`H(2,5) = −d`），
不含任何位移因子。這就是第 3 關 `det O₂ ≈ 1` 的來源。

**條件 C 已量到，誤差 0.005**：formB_ws 的 H₂ b 欄過零時間分成兩族 ——

```
t = 2.000 2.500 3.000 3.500 …  h̄_d = 4.22 / 2.00   ← 條件 B(轉折點)
t = 1.449 1.577 2.422 2.578 3.422  h̄_d = 2.1291~2.1312
                                   1 + b̂ = 2.1250~2.1256   差 +0.004~+0.006  ← 條件 C
```

canonical 振盪帶是 h̄ ∈ [2.0, 4.22]，而 `1 + b̂ = 2.125` **就在帶內**，所以軌跡
**每個振盪週期穿過它兩次**。這件事 `run_formB_ws.m` 的 header 早就寫了
（"the production J_b vanishes at w_bar = 1 + b_hat, inside the canonical oscillation band"），
本節只是把它量出來對上。

⭐ **由此得到一個可以拿去做設計的結論**：formC_b 的 b（CRLB/prior 0.86）比 formB_ws 的 b
（4.48）好 5.2×，差別**不在資訊多寡而在多了一個退化條件** —— 兩者都受條件 A/B 影響，
但只有 formB 的參數化額外帶了條件 C。**參數化的選擇會製造或消除內部退化點**，
這是第 3 關唯一能事先看出來的東西（第 4、5 關只看得到總分變差）。

**兩個形式的機制對照（同上條件）**：

| | formC_dist：slot 5 = δa | formC_b：slot 5 = b |
|---|---|---|
| F_e(4,5) | `1`（結構常數） | `−(1−â)²/b̂² · (Δw̄_d + (1−λc)δŵ₃)` |
| H(2,5) | `−d`（結構常數） | `(1−â)²/b̂² · ∇_d w̄_d` |
| det O₂ / scale² | 1.00 ± 0.03，7680 步無一步近 0 | — |
| hold CRLB / prior | 4–7× | **23000×**（初始 hold）、580×（末端 hold） |
| 最佳 CRLB / prior | **0.032**（好 31×） | **0.86**（勉強打平，飽和值） |
| 資訊來源 | y₁ 97%（y₂ 差 37×） | y₁（y₂ 差 30×） |

讀法：δa 的可觀性由**結構常數**擔保，連 hold 都不退化；b 的兩條路**同時** ∝ 位移，
hold 就是 ③ 條件退化，而且整個場景裡 b 的資料資訊最多只跟 prior 打平 ⇒ 「估 b 買不到
準度」是**資訊界限的結果，不是實作問題**。

---

## 最後一句：過了五關不代表值得做

```
不可觀                → 不准上
可觀但 CRLB 輸 prior  → 不准上（實務不可辨識）
可觀且 CRLB 贏 prior  → 才有資格問「它要修的誤差有沒有變小?」(配對差,第 9 條)
```

δa 五關全過，但真值本身 ≈ 0（S3(b) 一週期積分恰為零）⇒ 估它沒有回報。
**它不是不可觀，是沒東西可估。** 這兩件事不可混為一談。
