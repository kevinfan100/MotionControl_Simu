# γ/σ 對數增益分裂 — 白話說明

> 對應數學稿：`gamma_split_draft.tex`。這份是給人看的直覺解釋，不含推導細節。

> **2026-07-14 更新（折入 v-drift 三刀實測）**：
> 1. **曲率翻案（重要）**：原本以為「ln 轉移能減少下潛出口的曲率 spread」是 **錯的**。
>    用 repo 的 c_perp 實算：mobility a(h) 全程是凹遞減（a''<0），所以 ln 空間的分數曲率
>    |κ'| = |a''/a| + κ² **永遠比 a-space 大**（近壁 h̄=1.2 大 3.4×、h̄=1.11 大 4.9×）。
>    指數 mobility 的「κ'=0 精確」特例不適用近壁。**結論：下潛出口 6% spread 不能靠改 ln 解**，
>    要靠「下潛期不更新 γ」（見 §1b）；ln 分裂的真正贏點是 C3-kill + 拆焊點，不是曲率。
> 2. **C3 自錨定罪**：A3 的 -0.48%/cycle 系統 bias（-22σ）來自 a'=â·K_h 的自我參照通道 C3；
>    A2 的 C3≈0。ln 分裂裡 κ=-K_h/R 不含 â，**結構性消掉 C3**（升成 boxed 頭條）。
> 3. **y2 可能是死通道**：knife-3（y2 全關）五指標不動 → 現結構下 y2 是死的。分裂賭「拆焊點能
>    喚醒 y2 餵 γ」，但 y2 每步獨立資訊只有 ~1/146，γ 的價值只能靠 Q_γ=0 累積 + 三軸共享，
>    不是每步強度。這是全設計最大的賭注。

## 一句話

把每軸的 motion gain `a_i` 改寫成「共用的絕對水準 γ」加「各軸的形狀 σ_i」，
用兩個獨立的 state 分開估計，讓 **level（水準）** 有自己的 covariance，
不再被 taylor EKF 現有的 `P44 = a'²·P33` 焊死在 `dx3_hat` 上。

## 為什麼要做這件事

現在 4-state taylor EKF 裡，gain state `a` 和位置誤差 state `dx3` 被一條精確的
filter 不變量 **綁死**：

```
P44 = a'² · P33 ,   P34 = -a' · P33   (frozen a' 下嚴格成立)
```

這條「焊點」的後果是：level 資訊只能透過 y2 (a_xm) 進來，y1（位置量測）對 level
的貢獻被靜音。於是 A2/A3 的 level std 卡在 2.0–2.2%，降不下去。

分裂的目的就是 **拆掉這條焊點**：給 level 一個獨立的 state γ、獨立的 covariance，
讓 y1 也能幫忙估 level，並且讓 level 隨時間累積資訊而收斂。

## 核心參數化

```
ln a_i = γ + σ_i
  γ    = ln(Ts/γ_N)      ← 所有軸共用，只跟 bead + 流體有關（Stokes 各向同性）
  σ_i  = -ln c_i(h̄)      ← 各軸的壁面形狀，全部的 h̄ 依賴都在這
  κ_i  = a'_i / a_i = -K_h,i(h̄)/R   ← 對數斜率，只跟牆幾何有關
```

關鍵：**γ 是同一顆珠子在同一種液體裡的 bulk drag，三軸只有一個**。這是物理
（Stokes 各向同性），不是「假設 c_i(h̄) 長什麼樣」——所以它完全符合 model-free 約束。

## 三個最重要的性質（為什麼這樣分會贏）

### 1. 對數轉移對 level error 免疫（第 2 節）
a-space 裡增量是 `Δa = a'·Δh`，而 a' 正比於 gain 水準。若 â 有個倍率誤差 g
（â = a/g），用 â 算出來的 a' 會讓增量整條差 1/g，**會累積成漂移**。
換到 ln-space，增量變成 `Δσ = κ·Δh`，而 `κ = -K_h/R` 裡的 â 直接約掉。
一個常數 level 誤差只變成 γ 上的一個 DC 偏移（被 γ 吸收），**完全不污染 σ 的轉移**。
等於用「A3 的可實作性（斜率用 â 算）」換到「A2 的 level 免疫性（本來要 oracle）」。

### 2. γ 收不到 process noise（第 3 節，可證）
thermal force 和 sensor noise 會擾動 δx、進而透過壁面相依的 mobility 擾動 σ，
**但它們不會改變 bulk drag γ_N**。所以 rank-1 noise 向量 `q = ε·[0,0,-1,κ,0]` 的
γ 分量恰好是 0——這是結構性的，不是近似。唯一能動 γ 的是溫度（改黏度 η）：
水的 `d(ln a)/dT ≈ +2.3%/K`，實驗室 stage 穩定在 ΔT ≤ 0.1 K 時，整段跑下來 γ 只飄
< 0.23%，遠小於 σ 那幾 %。所以 **Q_γ = 0 站得住腳**（4–60 秒的 run）。

### 3. hold / 遠場時只是「凍結」，不會發散（第 6 節）
當 κ→0（遠離牆，或 hold 高度不動），σ 和 γ 的「差」方向（e_d = e_σ - e_γ）
既收不到 process noise、也不被 y1/y2 觀測到。但它的動態是純積分器 + 零雜訊，
所以 P 在那個方向 **不動**（有界、非增），不是發散。level 的「和」方向仍然被
y2 看得到，所以 â 一直是準的，只是「拆分」暫停。等軌跡再掃過牆、κ≠0，拆分自動恢復。
（這裡只講 covariance 的行為，**沒有**過度宣稱 Gramian rank 結果。）

## 三軸怎麼共用 γ（第 7 節）

covariance 長成 **箭頭矩陣（arrowhead）**：三個各軸 4×4 對角塊 + 一條 γ 的
row/col 把三軸串起來。三軸各自的 y2 (a_xm,i) 都在量同一個 γ，Kalman update 會
**自動**依各軸 R22,i（含 sensor floor ξ_i）做 precision-weighted 融合——a_xm 乾淨
的軸（R22 小）對 γ 貢獻大。三個獨立量測 → level 的 variance 最多再降 √3。

x/y 軸的 gain 參數是「壁面法向高度」（是 z 的量），所以它們的 σ_i 由 z 的運動驅動；
實作上把 z 的轉移當 known input 餵進去（跟現有 code 一致），process noise 用 z 的
residual σ²_ε,z。但 x/y 的**位置**列仍透過自己的 gain error 耦合到共用 γ，所以
y1,i 也帶一點 level 資訊。

## 風險（誠實，第 8 節）

- **早期鎖定**：Q_γ=0 → γ 的 gain 以 ~1/k 衰減，很早就定住。若早期 y2 的 level 有
  systematic bias，會 **永久** 留在 γ 裡。這裡有一個 load-bearing 的未解推導：
  a_xm 反解目前 **假設 g=1**（â=a），在 g≠1 時它的 level 到底準不準 **尚未證明**。
  若 a_xm 的 level 有偏，γ 會永遠繼承這個偏。緩解：給 Q_γ 一個很小的 floor、
  或等掃過牆（κ 豐富）再讓 γ 定案、或 γ gain 做 fade-in。
- **前置條件**：A2 在「descent 出口」有 ~4.9% 的 level spread，這個機制要先查清楚，
  否則 Q_γ=0 會把出口那一刻剛好落在的錯 level 凍住。
- **好消息**：A4 self-diff 的 a' 雜訊是「斜率/形狀」量，只進 σ，γ 是一階被屏蔽的。

## 預先登記的預測（可證偽）

| 指標 | 現在（焊死） | 單軸分裂 @4s | 共用 γ 分裂 @4s |
|---|---|---|---|
| A2/A3 level std | 2.0–2.2% | ~1.3% | ~1.0–1.2% |
| 長 run scaling | — | 1/√T（γ 是無雜訊積分器） | 1/√T |

**證偽方式**：規劃中的 30–60 秒 run 要看到 level std 按 1/√T 下降；若它 plateau，
代表要嘛實際 Q_γ≠0（溫度或 a_xm bias），要嘛 a_xm 的 level 本身有偏（早期鎖在錯 γ）。
