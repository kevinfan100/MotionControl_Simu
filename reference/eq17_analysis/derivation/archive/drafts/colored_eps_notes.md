# Colored-ε MA(2) 精確記帳 — 白話說明

> 對應數學稿：`colored_eps_draft.tex`。這份給人看的直覺解釋，不含推導細節。
> 這就是專案裡講很久的「Path B 增廣」，終於為 4-state 做出來。

## 一句話

現在 KF 把閉迴路殘差 ε 當成「白噪」處理，但 ε 其實是 **有色的 MA(2)**（帶兩步記憶）。
做法：把「過去兩步的熱力踢動」`w[k-1]`、`w[k-2]` 各自升成一個 state（`m1`、`m2`），
於是那兩個 lag 從「雜訊」變成 **確定性耦合**，每步真正的 process noise 只剩一個
乾淨的白色 `w[k]`。這樣 innovation 會被漂白，P 會變誠實。

## 為什麼要做

ε 是 δx3 那條 error dynamics 的驅動雜訊，它長這樣（`β := 1-λc`，`w[k]:=a[k]·f_T[k]`）：

```
ε[k] = w[k] + β·(w[k-1] + w[k-2]) + β·n_x[k]
```

d=2 的延遲補償把「過去兩步的熱力踢動」也搬進了控制律，所以 ε 帶了兩步記憶
（MA(2)）。把它當白噪，KF 就會：

1. **innovation 不白** — 實測 M0 濾波器的 y1 innovation ACF：ρ(1)=+0.320、ρ(2)=+0.258，
   ρ(3以後)≈0。這正是 ε 的 MA(2) 指紋沒被建模、漏到 innovation 裡。
   （理論值 ρ(1)=0.3305、ρ(2)=0.2542，吻合。）
2. **P 過度自信** — 有色當白會在 DC 高估獨立資訊 `1+2(ρ1+ρ2)=2.17` 倍，
   所以 P44/Var(e_a)=0.415（1/2.17≈0.46，對得上）。

## 核心：兩個「雜訊記憶」state

```
m1[k] := w[k-1]        → 動態 m1[k+1] = w[k]   （被新雜訊驅動）
m2[k] := w[k-2]        → 動態 m2[k+1] = m1[k]  （純平移）
```

有了 m1、m2，`β·(w[k-1]+w[k-2]) = β·(m1+m2)` 就變成「當前 state」，可以放進 F_e
當確定性耦合，不再是雜訊。結果：

- **δx3 那列**：m1、m2 欄各加 `-β`；process noise 只剩 `-w[k]`（白）。
- **a（gain）那列**（taylor 傳輸帶 a'·ε）：m1、m2 欄各加 `+a'·β`；noise 只剩 `+a'·w[k]`。

## Q 變成 rank-1（第 3 節，重點）

一個 `w[k]` 同時踢 δx3（係數 -1）、a（係數 +a'）、m1（係數 +1），所以

```
q = w[k]·[0, 0, -1, a', 0, +1, 0]ᵀ  →  Q_th = σ²_w · qqᵀ,  σ²_w = 4kBT·â
```

非零項：Q33=σ²_w、Q34=-a'σ²_w、Q44=a'²σ²_w，外加 **交叉項** Q36=-σ²_w、Q46=+a'σ²_w、Q66=σ²_w。

### 最關鍵的和解（結束 Path C vs Path A' 的老爭論）

```
Q33:  (1+2β²)σ²_δh  →  σ²_δh   （回到 per-step 白色，就是老 Path C strict 的值）
```

但被拿掉的那塊有色 `2β²σ²_δh` **沒有消失**，它 **搬進了 m-state**。實際算一下：
兩個 m 注入 δx3 的變異數 = `β²·(σ²_w[k-1]+σ²_w[k-2]) = 4kBT·β²·(â[k-1]+â[k-2])`，
這 **正好等於** 現在 code 裡 `Q33_thermal` 的 lag 項（`motion_control_law_eq17_4state.m` L986）。

所以這個增廣是「精確的第三條路」：
- 不像 Path C strict（把 lag 直接丟掉 → P 低估 ~50%）
- 不像 Path A'（把 lag 硬灌成白色 inflation → 被否決的 hack）
- 而是把同一份變異數記在 filter **學得到** 的 state 上（m 透過延遲鏈被 y1 觀測）。

### 現有 Q33 其他兩項怎麼辦

- `Q33_randgain`（δx_δaf 增益擾動項）：**維持原樣**。它是另一種二階有色雜訊
  （過去 f_d × 過去 gain increment 的乘積），要精確做得再增廣 Δa_ram 歷史；量很小，
  當白色 inflation 可接受。
- `Q33_nx = β²σ²_n`（β·n_x 回授項）：**維持原樣**，但它其實跟量測相關 → 見下。

## 一個沒完全處理的相關性（第 4 節）

ε 裡的 `β·n_x[k]` 跟 y1 的量測雜訊 `n_x[k]` 是 **同一個** n_x（控制律用了延遲量測 δx_m[k]）。
所以 process noise 跟 measurement noise 相關，S≠0：

```
S(3,1) = -β·σ²_n,   S(4,1) = +a'·β·σ²_n
```

精確解是「相關雜訊的 modified Kalman gain」（Simon 書第 7 章），但 **建議 DEFER**：
這只擾動 `β²σ²_n` 那一小塊。相對熱力 Q33 的比例 `r = β²σ²_n/(4kBT·a)`：

| h̄ | 1.5 | 2.0 | 3.0 | 5.0 | 10 | 遠場 |
|---|---|---|---|---|---|---|
| r | 11.5% | 7.6% | 5.6% | 4.6% | 4.0% | 3.6% |

（repo 感測器 10 nm、β=0.3）。r 是二階小項上的 O(10%) 修正，安全可延後；現有 code 本來就把
這塊當「獨立雜訊」灌進 Q33，增廣照舊繼承。

> **⚠ 對 seed 的兩點更正**：seed 說 r≈1%（遠場）且「近壁更小」。實際用 repo 的 10 nm 感測器，
> **遠場 r≈3.6%**，而且 r 是 **往牆靠會變大**（近壁 a=a_nom/c_⊥ 變小 → σ²_w=4kBT·a 變小 → r 變大）。
> 1% 那個數字要感測器 ~5 nm 才對。bound 兩種算法都安全，但單調方向和量級跟 seed 相反，已寫進稿子。

## 觀測性、初始化、組合（第 5 節）

- **觀測性**：m1、m2 是雜訊 state，透過 δx3 列的 -β 耦合，沿延遲鏈 δx3→δx2→δx1→y1 被看到
  （跟 AR(1) 的 v-state 靠 y2 被看到是同一種機制）。結構性可觀，不需要 PE。
- **初始化**：m̂=0、`P_mm(0)=σ²_w(0)=4kBT·â(0)`、cross=0；DARE seed 加兩列/欄即可；每軸各自帶 m1、m2。
- **組合**：
  - 跟 AR(1) v-state **正交**（不同雜訊 w vs w_v、不同通道 y1 vs y2）→ 兩個 block 疊加即可。
  - 跟 gamma-split **正交**（m 只耦合到 σ，不碰 γ；γ 無雜訊的證明保住，γ 那列/欄在 m-block 全零）。

## 這個修正買到什麼（第 6 節，可證偽）

| 量 | before (M0) | after (預測) |
|---|---|---|
| innovation ρ(1) | +0.320 | ≈0（漂白）|
| innovation ρ(2) | +0.258 | ≈0 |
| P33 honesty | ~0.4 | ~1 |
| P44 honesty | 0.415 | ~1 |
| gain std (A2) | 2.53% | 頂多改善 ~10-15%（未證）|
| gain bias (A2) | -0.37% | ≈不變 |

- **(a) 漂白**：把 MA(2) 建對，innovation 就白（KF 白性恢復）。這是主要驗收指標。
- **(b) P 誠實**：拿掉 2.17× 的 DC 資訊高估，P33 與 P44 的 honesty 都回到 ~1
  （兩者被 `P44=a'²P33` 焊在一起）。
- **(c) 買不到的**：資訊下限（CRLB）跟模型無關，所以 **實際 std 幾乎不會變好**，bias 也不變。
  這個修正修的是「filter 對自己的信心（P、innovation）」，不是「準度」。誠實 ≠ 準。

## 驗證計畫（未來實作用，現在不做）

1. **Gate-1 knob-off bit-identity**：增廣藏在 knob 後（預設關）→ 66 陣列 diff=0。
2. **innovation 白性（主驗收）**：y1 innovation ρ(1)、ρ(2) 從 +0.32/+0.26 → 0。
3. **honesty**：P33、P44 的 honesty 從 ~0.4 → ~1。
4. **20-seed 五指標配對** vs M0。
5. **下潛段 RMSE [0.5,1.5)s 當判別器**：下潛 wander（1.40 vs 2.61%）到底是「記帳錯」還是
   「聽 y1 的合理代價」。**兩個結果都預先登記為可接受**：
   - wander 降回 ~1.40% → 之前是誤記的有色雜訊，增廣賺回來；
   - wander 不動 → 那是活 y1 鏈的真實代價。
   這個判別器是用來決定「下潛期要不要 gate γ」，不是 pass/fail。
