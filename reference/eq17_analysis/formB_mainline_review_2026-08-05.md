### 4.4 簡併天花板（結構性）

p = 1 時 Form B 可精確線性化：

```matlab
Y = a_bar/(1 - a_bar) = (w_bar - w_s)/b     % 一條直線
% b = 1/斜率 ,  w_s = x 截距
```

⇒ b 與 w̄_s 的關係就是**同一條直線的斜率與截距**。耦合強度閉式 **[推]**：

```matlab
|cos(dA/db, dA/dws)| = 1/sqrt(1 + CV^2)
% CV = gap u 在有效權重 phi = rho/(b+u)^4 下的變異係數 (rho = 資訊率 ∝ v_d^2/a^2)
```

實測作業軌跡：⟨u⟩ = 1.85、sd = 1.08、**CV = 0.584 → |cos| = 0.8635**（閉式與數值相符）。
弱/強資訊比 7.3%。

去耦 pivot（推導值，非擬合）：`u_ref = <u²>/<u> = 2.4845 → w̄_ref = 3.485（h = 7.84 µm）`，
