> 來源：2026-07-28 從「p prior 怎麼推出來」結晶的跨 controller 通用方法。
> 實例與數字見 auto-memory `project-param-prior-and-container-rules-2026-07-28`

## 規則 1：模型參數沒有真值 ⇒ prior 只能從它自己的變異來

對物理量（a_h、σ_n）真值存在，P[0] = E[(真值 − 初值)²] 良定。
對**形狀參數**（power law 的 p、exp gain 的 b、任何指數/階數）真值不存在——
它是近似模型的參數，真曲線不欠它一個常數。唯一可辯護的替代定義：

```
參數的「真值」:= θ_eff(h̄) = 在每個高度上讓模型斜率等於真斜率所需的值
⇒ E[(真值−初值)²] → sup over 定義域 |θ_eff(h̄) − θ₀|²
```

誤差兩來源：(a) 無知（不知道常數多少）、(b) 形狀失配（局部指數本來就隨位置變）。
**有解析錨時 (a) ≡ 0**（兩個獨立漸近極限給同一值），只剩 (b)。
反向用法：手上有錨卻掛一個寬 prior = 自相矛盾，不是保守。

## 規則 2：變異是命令驅動就屬前饋，不屬 Q

```
θ_true[k+1] − θ_true[k] = (dθ_eff/dh̄)·Δh̄_d[k]   ← Δh̄_d 是自己下的命令，確定性
```

| 性質 | 該進的容器 |
|---|---|
| 確定性、命令驅動、相干累積 ∝ N | prediction 前饋（F_e / recursion） |
| 隨機、白、擴散 ∝ √N | Q |

**放錯容器補不回**：√N 追不上 N（實測短 5×），放大 κ 只弄髒 hold。
`Q ∝ Δh̄_d²` 的閘門形式本身是對的（hold 歸零），錯的是拿它當主要修法。
精確前饋通常被 c-free 封死；估它 = 回 Taylor 階梯 regress。**正解是第三扇門：換形狀。**

## 規則 3：prior 必須匹配種子精度，不能為了「留修正空間」放寬

太緊 → 收斂慢到精確命中預算律；太鬆 → 被噪聲拉跑。兩邊都壞 ⇒ 不是可調參數。
種子誤差用推導算（例：截斷首項 ⇒ 相對誤差 = A²/h̄₀²，per-axis），不是擬合。

## P[0] 推導六步鏈（照抄）

```
1. P[0] := E[(真值 − 初值)²]                       KF 定義
2. 初值 := 由解析錨決定                             ⇒ 來源 (a) 歸零
3. 模型參數非物理常數 ⇒ 真值 := θ_eff(h̄)
4. Q = 0（當常數）⇒ 一個數服務全程 ⇒ 誤差 = |θ₀ − θ_eff(h̄[k])|
5. k=0 時 h̄ 未知且會掃過定義域 ⇒ 誠實的界 = 全域 sup
6. √P[0] = sup |θ_eff − θ₀|
```

## 兩個驗收工具

- **P[0] 是預算**：Q=0 的 state 滿足 E[(x̂∞−x̂₀)²] = P[0] − P[∞]。
  一致性檢查：需要走到的最遠處 ≈ √P[0]，剛好夠、不多給。上限被撐破 = 濾波器不自洽。
- **形狀驗收**：sup|θ_eff − θ₀| ≲ √P[0] ⟺ Q_θ = 0 誠實。
